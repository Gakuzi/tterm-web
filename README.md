# tTerm Platform & Orchestration (Приватный репозиторий)

Платформа для удалённого управления серверами, рабочими станциями, защищёнными терминальными сессиями и оркестрацией ИИ-агентов. Проект включает веб-интерфейс, агент для машин, Telegram-бот управления с Rich Messages и строгую мультитенантную изоляцию данных.

---

## 📌 Ключевые возможности

1. **Строгая изоляция пользователей (Multi-Tenancy):**
   - Полное разграничение проектов, виртуальных узлов, git-репозиториев и секретов хранилища (Vault).
   - Пользователь видит только свои машины и проекты. При отсутствии машин выдаётся чистая карточка с инструкцией подключения.
2. **Интерактивный Telegram-бот (@ttermnofbot):**
   - Построен на базе **Telegram Rich Messages**: карточки серверов с встроенными кнопками внутри сообщения.
   - **Панель управления владельца:** доступна только по Telegram ID `55570186` (`@eklimov`). Управление пользователями, блокировки, тарифные планы, отвязка устройств, статистика.
   - **Безопасность команд:** административные слэш-команды изолированы через `BotCommandScopeChat` и не видны обычным пользователям.
3. **Безопасность и криптография:**
   - Встроенный Signer CA (ED25519) для выпуска временных сертификатов доступа.
   - Защищенное хранилище SSH-ключей (Vault) с клиентоориентированным шифрованием.
4. **Внешняя память проекта для ИИ (.ai/):**
   - Папка `.ai/` содержит полную архитектуру, брендбук и статус для работы с LLM без раздувания контекста.

## 🚀 Быстрый старт на сервере

### 1. Требования
- Docker и Docker Compose
- Python 3.12+
- PostgreSQL 16 (входит в docker-compose)

### 2. Запуск через Docker Compose
```bash
docker compose up -d --build
```

Контейнеры:
- `tterm-server-tterm-1`: ядро FastAPI + Signer + Telegram Bot (порты `8290`, `8291`).
- `tterm-server-db-1`: база данных PostgreSQL (`tterm_web`).

### 3. Переменные окружения (.env)
```env
TTERM_DATABASE_URL=postgresql://tterm:secret@db:5432/tterm_web
TTERM_SIGNER_KEY_PATH=/app/data/.signer_ca.key
TTERM_OWNER_EMAIL=eklimov84@gmail.com
TTERM_TELEGRAM_BOT_TOKEN=<TELEGRAM_BOT_TOKEN>
TTERM_TELEGRAM_OWNER_ID=55570186
```

## 🧪 Запуск тестов

Тесты запускаются внутри контейнера или локально в виртуальном окружении:

```bash
# 1. Тест мультитенантной изоляции (проекты, узлы, git, vault)
docker exec -w /app tterm-server-tterm-1 python3 -m unittest tterm/tests/test_tenant_isolation.py

# 2. Тест разграничения прав и админ-панели Telegram-бота
docker exec -w /app tterm-server-tterm-1 python3 -m unittest tterm/tests/test_bot_admin.py
```

## 📁 Структура репозитория

```
├── .ai/                       # Архитектура и память проекта для ИИ-агентов
│   ├── ARCHITECTURE.md        # Архитектурное описание модулей, портов и базы
│   ├── BRANDBOOK.md           # Брендбук, реквизиты, ЭДО, фирменный стиль
│   └── PROJECT_STATE.md       # Актуальный статус разработки и верификации
├── docker-compose.yml         # Конфигурация Docker-сервисов
├── Dockerfile                 # Сборка контейнера tTerm
├── tterm/
│   ├── core/                  # Авторизация, аккаунты, SSH, криптография
│   ├── orchestration/         # API, Telegram-бот, discovery, управление машинами
│   └── tests/                 # Модульные и интеграционные тесты
└── web/                       # Фронтенд (React / SPA)
```

## 🤖 Инструкция для работы с ИИ-ассистентами
При начале нового сеанса программирования направляйте модель читать файлы в каталоге [`.ai/`](file:///.ai/):
> *«Прочитай .ai/ARCHITECTURE.md и .ai/PROJECT_STATE.md. Переходим к задаче [...]»*
Это гарантирует мгновенную ориентацию модели в кодовой базе и экономит до 95% токенов.
