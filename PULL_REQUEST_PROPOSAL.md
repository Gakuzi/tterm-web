## 🎯 Введение и цель доработок

Денис, привет!

Прежде всего хочу выразить огромное уважение за **tTerm** — архитектура решения, чистота веб-сокетов, скорость работы и внимание к деталям заслуживают высшей оценки. Сервис получился невероятно лёгким, отзывчивым и удобным.

Мы развернули tTerm на собственном сервере (Raspberry Pi 5) для ежедневного использования в реальных задачах и в процессе активной эксплуатации разработали комплексное расширение возможностей, которое решает 4 главные задачи, стоящие перед современными терминальными системами:

1. **Поддержка компьютеров на Windows** (ранее сервис работал только с macOS и Linux).
2. **Встроенная интеграция с Git / GitHub прямо в интерфейсе** (работа с коммитами и синхронизацией без необходимости вручную вбивать длинные команды).
3. **Встроенный ИИ-помощник при ошибках** (объяснение причин сбоя команды и кнопка автоматического исправления в 1 клик).

5. **Переименование компьютеров (машин)** прямо из веб-интерфейса.

Все изменения выполнены с **полным сохранением обратной совместимости (Zero Breaking Changes)**, в строгом соответствии с твоими стандартами кода, правилами интернационализации (`strings.mjs` на 12 языках) и принципом безопасности «no root».

## 📑 Детальное описание добавленных функций и методов

### 1. Поддержка Windows (PowerShell-агент и инсталлятор в 1 клик)

В оригинальной версии скрипт `install_computer.sh` поддерживал только `Darwin` (macOS) и `Linux`. Пользователи Windows оставались без нативного подключения.

#### Что добавлено:
* **Инсталлятор и агент:** [`tterm/templates/install_computer.ps1`](file:///Users/evgeniy/Documents/antigravity/tterm-web/tterm/templates/install_computer.ps1).
  * **Не требует установки Python на Windows** — написан на чистом PowerShell с использованием встроенного в Windows .NET `System.Net.WebSockets.ClientWebSocket` и `System.Diagnostics.Process`.
  * Генерирует криптографически стойкий 32-байтный URL-safe ключ компьютера в `%USERPROFILE%\.tterm-web\env.json`.
  * Автоматически настраивает автозагрузку в папку Startup пользователя (`tTermAgent.lnk`), запускается в скрытом фоновом режиме (`-WindowStyle Hidden`).
* **Эндпоинты в `tterm/api/connect.py`:**
  * `GET /c/{token}.ps1`: возвращает сгенерированный PowerShell-скрипт с подставленными `$HUB` и `$TOKEN`. Команда подключения в Windows:
    ```powershell
    irm http://<host>:8291/c/<TOKEN>.ps1 | iex
    ```
  * `GET /c/{token}.bat`: отдает готовый исполняемый batch-файл `tterm-setup.bat`. Пользователь на Windows может просто скачать файл и дважды кликнуть по нему — компьютер сразу подключается к кабинету.
* **Паспорт системы Windows в `tterm/core/passport.py`:**
  * Добавлен `POWERSHELL_SCRIPT`, собирающий через WMI/CIM информацию о версии Windows, процессоре, RAM, свободном месте на дисках и доступных командах.
  * В `tterm/core/agents.py` добавлено автоопределение ОС (`link.os.lower().startswith("win")`) для корректного опроса паспорта.
* **Интерфейс в `web/src/AddMachine.tsx`:**
  * Появился аккуратный переключатель платформы: **«macOS / Linux»** и **«Windows (PowerShell)»**.
  * Для Windows выводится как готовая команда для PowerShell, так и кнопка **«Скачать установщик (tterm-setup.bat)»**.

### 2. Кнопки Git и GitHub прямо в окне терминала

Для людей, работающих с кодом, постоянный ввод `git status`, `git add -A && git commit -m "..."`, `git push` отнимает много времени и чреват опечатками.

#### Что добавлено:
* **Компонент в `web/src/InputLine.tsx`:**
  * Терминал отслеживает `prompt.branch` (ветка уже детектируется шеллом tTerm). Как только пользователь переходит в папку с Git-репозиторием, над строкой ввода появляется умная панель:
    * 📋 **«Статус»**: в один клик выполняет `git status -s` и показывает измененные файлы.
    * 💾 **«Закоммитить»**: открывает всплывающее окно (popover) фиксации изменений.
    * 🚀 **«Push»**: выполняет `git push` в удаленный репозиторий.
    * ⬇️ **«Pull»**: скачивает свежие изменения `git pull`.
* **Умный генератор текста коммита (с поддержкой ИИ)**:
  * В окне коммита есть кнопка **«✨ ИИ-комментарий»**, предлагающая понятный текст на русском языке в зависимости от контекста.
  * Добавлены быстрые теги в один клик: `[🐛 Фикс]`, `[✨ Новое]`, `[⚙️ Настройки]`.
  * Две кнопки сохранения: **«Закоммитить»** и **«Коммит и Push 🚀»** (выполняет `git add -A && git commit -m "..." && git push`).

### 3. Встроенный ИИ-помощник при ошибках выполнения команд

Если команда в терминале завершается с ненулевым кодом выхода, пользователю часто непонятно, что именно произошло и как это исправить.

#### Что добавлено:
* **Компонент в `web/src/BlockView.tsx`:**
  * Рядом с красным кодом ошибки (`exitCode !== 0`) отображается аккуратная фиолетовая кнопка с иконкой искры: **«Помощь ИИ»**.
  * Функция `diagnoseError(command, exitCode)` анализирует команду и вывод:
    * Код `127` (Command not found) -> объясняет, что программа не найдена, и предлагает `which <cmd>` или команду установки.
    * Код `126` (Permission denied) -> предлагает запуск с правами суперпользователя `sudo <cmd>`.
    * Ошибки `git push` (non-fast-forward / rejected) -> объясняет необходимость синхронизации и предлагает `git pull --rebase`.
    * Ошибки прав `docker` -> предлагает запуск с `sudo` или добавление пользователя в группу `docker`.
    * Ошибки блокировки `apt` / `dpkg` -> предлагает команду снятия блокировки `fuser -vki /var/lib/dpkg/lock-frontend`.
    * Сигнал `137` (SIGKILL / Out of Memory) -> объясняет исчерпание RAM.
    * Сигнал `130` (SIGINT) -> прерывание через Ctrl+C.
  * Кнопка **«⚡ Исправить: <команда>»**: при нажатии предложенная исправляющая команда автоматически подставляется и исполняется в активном терминале через колбэк `onRunFix` в `web/src/FeedTerminal.tsx`.

### 4. Полноценный MCP-сервер и управление безопасностью ИИ

Для взаимодействия с внешними автономными агентами (Google Antigravity, Claude Desktop, Cursor AI) реализован протокол Model Context Protocol.

#### Что добавлено:
* **MCP-сервер:** [`mcp_server.py`](file:///Users/evgeniy/Documents/antigravity/tterm-web/mcp_server.py).
  * Реализует JSON-RPC 2.0 по стандарту Model Context Protocol (stdio).
  * Инструменты, доступные ИИ:
    * `tterm_list_machines`: список компьютеров, статус подключения, ОС, пользователи.
    * `tterm_rename_machine`: переименование компьютера.
    * `tterm_list_terminals`: список открытых сессий и запущенных процессов.
    * `tterm_open_terminal`: создание нового терминала на любой подключенной машине.
    * `tterm_run_command`: выполнение команды в существующем терминале с возвратом вывода.
    * `tterm_exec`: автоматический запуск изолированной команды и чтение результата.
    * `tterm_read_terminal`: чтение логов и истории экрана.
* **CLI-утилита:** `tterm-cli` для работы с терминалами из скриптов и терминала.
* **Раздел настроек в веб-интерфейсе (`web/src/AiSection.tsx`)**:
  * Вкладка **«ИИ и MCP»** в окне настроек (Settings).
  * **Мгновенный отзыв доступа (Revoke Access):** большая кнопка «Отозвать доступ ИИ», деактивирующая внешние токены, и кнопка «Перевыпустить ключ».
  * **Режим подтверждения команд (Guard Rails):** переключатель, при котором ИИ не может выполнять деструктивные команды без аппрува человеком.
  * **Режим только для чтения (Read-Only):** запрет записи для ИИ.
  * Готовые конфигурации для Google Antigravity, Claude Desktop и Cursor AI с копированием в 1 клик.
  * Инструкция по безопасному распределению командных ролей (**Owner, Admin, Member, Viewer**).

### 5. Переименование компьютеров (машин)

Раньше компьютеры отображались только под системными именами (`klim`, `DESKTOP-89F1`). В базе данных колонка `name` уже была предусмотрена, но не было API-метода и поля ввода в UI.

#### Что добавлено:
* **В `tterm/core/machines.py`:**
  * Функция `async def rename(pool, user_id, machine_id, name)`: проверяет права (`owner`, `admin`, `member`), длину строки (1-64 символов), уникальность имени в проекте и делает запись в журнал аудита `machine.renamed`.
* **В `tterm/api/page.py`:**
  * Эндпоинт `PATCH /api/machines/{machine_id}` с валидацией через Pydantic `MachinePatch`.
* **В `web/src/Sidebar.tsx` и `web/src/App.tsx`:**
  * Двойной щелчок по названию компьютера в боковом меню открывает редактирование имени (аналогично терминалам).
  * Сохранение по нажатию `Enter` или потере фокуса.
