## 3. Правила для новых сессий с ИИ
При открытии нового диалога с нейросетью:
1. Изучать файлы `.ai/ARCHITECTURE.md`, `.ai/BRANDBOOK.md` и `.ai/PROJECT_STATE.md`.
2. Не сканировать заново весь диск и не запускать многомегабайтные дампы.
3. Каждую задачу завершать обновлением `.ai/PROJECT_STATE.md`, прогоном тестов и фиксацией коммита на русском языке с пушем на GitHub.
